# DiscordBot

DiscordBot is a simple Discord bot designed to interact with users on a Discord server. It uses the discord.py library to handle commands and events, and the python-dotenv library to manage environment variables. The bot can be customized with various commands and features to enhance server interactions.

## Install

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/DiscordBot.git
   cd DiscordBot
   ```

2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Create a `.env` file in the root directory and add your Discord bot token and command prefix:
   ```env
   DISCORD_TOKEN=your_discord_bot_token_here
   COMMAND_PREFIX=!
   ```

## Use

1. Run the bot:
   ```bash
   python bot.py
   ```

2. Invite the bot to your Discord server using the OAuth2 URL generated by the Discord Developer Portal.

3. Use the command prefix followed by the command name to interact with the bot. For example, type `!hello` in a channel where the bot has access to receive a response.
